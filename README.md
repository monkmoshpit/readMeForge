# readMeForge
> generate polished GitHub READMEs in seconds

![Open Source](https://img.shields.io/badge/Open%20Source-✓-3fb950?style=flat-square)
![TypeScript](https://img.shields.io/badge/TypeScript-blue?style=flat-square&logo=typescript&logoColor=white)
![License: MIT](https://img.shields.io/badge/License-MIT-yellow?style=flat-square)

A web tool that eliminates the blank-page problem when writing project documentation. Built to help developers ship professional READMEs faster.

## ✦ Features

| | |
|---|---|
| **Instant generation** - Customizable templates that adapt to any project type |
| **Multi-language support** - Write docs in the PT, EN and ES |

## ⚙ Stack

`TypeScript` · `CSS` · `HTML` · `Vite`

## ⬇ Install & run

```bash
npm install && npm run dev
```

See `package.json` for the full list of scripts.
